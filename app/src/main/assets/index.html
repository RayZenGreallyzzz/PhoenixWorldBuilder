🧱 Из моего GLB — стандартный модуль

Не замостить кусками: преобразовать один исходник в прямую деталь, угол, четверть круга или полукруг стандартного размера. Камень и рисунок повторно не копируются.

Выбери свой GLB в библиотеке → форму → кнопку. Затем «Сохранить в Мои». Для сложных декоративных/скелетных моделей подгонка может быть недоступна.

✦ Эмблемы, картины и надписи

Выбери установленную стену или пол. Эмблема наносится на поверхность без дополнительной 3D-плоскости.

Выбери установленную стену, нажми «Панно» и выбери картину. Редактор сам найдёт соседние стены в одной плоскости.
До 3 рисунков на одной детали. Выбери PNG из каталога эмблем, чтобы добавить его.
⚠ Изменить размер 3D-модели (включая толщину)

Эта настройка увеличивает саму плиту, стену и толщину. Для увеличения рисунка используй ползунок «Размер изображения» выше.

Размер по осям (самой модели)Ширина X • Высота Y • Глубина Z. Для стены Z обычно означает толщину, для пола толщиной является Y.
Для прямых стен, отдельных углов 90° и распознаваемых полукруглых стен. Длину и радиус не меняет.
Изменения применяются к выбранной детали. Кнопка «В Мои» отдельно сохраняет настроенный модуль для повторного использования даже без сохранения карты.
