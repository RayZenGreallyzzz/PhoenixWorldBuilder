🏠 Автоподрезка по границе стен

Выбери плиту пола или импортированный GLB типа «Пол». Подрезка учитывает прямые стены и углы на текущем этаже, срезая часть плитки за внутренней гранью стены. Встроенные дуги учитываются с приближением по коротким участкам; сложные импортированные кривые пока пропускаются.

Перед массовой обработкой сохрани проект. Результат можно сохранить в «Мои детали».
✂ Подрезка края плиты / плитки

Выдели стандартную плиту пола. Линия разреза проходит под заданным углом по X/Z; толщина плиты сохраняется, срез закрывается. Для внешнего края подгони угол и смещение.

✂ Точный наклонный срез GLB

Для статических импортированных GLB: режет геометрию по прямой под любым углом (плоскость вертикальна). UV сохраняются. У сложных моделей срез остаётся открытым; исходный GLB не изменяется.

✂ Правка своего GLB: обрезать / согнуть

Меняется только выбранная копия модели, оригинальный GLB в библиотеке остаётся целым. Обрезка по плоскости оставляет открытый край; скелетные модели не деформируем.

⚙ Торцы импортированной модели

Если GLB имеет нестандартную четверть круга, задай координаты центра двух торцов в метрах относительно модели и направления касательных наружу. Это позволяет соединять такие модели без угадывания по размеру.
