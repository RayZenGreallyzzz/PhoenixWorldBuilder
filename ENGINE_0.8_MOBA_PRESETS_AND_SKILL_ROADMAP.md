# Phoenix Engine 0.8 — MOBA управление + план Skill Editor

## Готово

Режим EDIT → **🎮 HUD / СКИЛЛЫ** → готовая раскладка:
- **Mobile Legends** — большой удар внизу справа, лечение рядом, навыки дугой, кнопка ульты выше.
- **Wild Rift** — компоновка с условными слотами Q / W / E / R.
- **Классическая** — первоначальная компоновка Phoenix Engine.

В редакторе есть шесть слотов: `attack`, `heal`, `slot3`, `slot4`, `slot5`, `ultimate`.
Порядок и координаты можно подстроить пальцем, изменить цвета, размеры, иконки,
подписи и включённость, затем сохранить. Значения хранятся в JSON проекта и
на устройстве. Движок поддерживает Android landscape и не запускает лишние
рендереры/циклы.

### Совместимость

Формат HUD переходит из версии 1 (четыре слота) в версию 2 (шесть слотов).
Старые проекты и сохранённые настройки 0.7 сохраняют положение первых четырёх
кнопок; новые два слота получают стандартные значения. Это миграция данных,
а не удаление прежних настроек.

**Игровые действия сейчас есть только у кнопок:**
- `attack`: ближний бой из Phoenix Combat.
- `heal`: лечение 30 HP, перезарядка 12 секунд.

Все остальные кнопки (включая Ultimate) — **настраиваемые слоты интерфейса**,
ещё без механики. Переименование слота не изменяет урон. Система наведения,
продвинутых AOE и дополнительных навыков ещё не реализована.

## Следующий модуль: настоящий Character Skill Editor (требование пользователя)

При редактировании **каждого игрового персонажа / префаба** разработчик сможет:
1. Открыть персонажа в EDIT → вкладку **Навыки**.
2. Добавить навык, выбрать его тип (удар, снаряд, лечение, защита, бафф,
   область, пассивный эффект).
3. Указать название, описание, картинку/иконку, готовый GLB-анимационный
   клип, визуальный эффект и способ наведения.
4. Настроить **базовый урон, прирост за уровень навыка, максимальный
   уровень навыка, кулдаун и стоимость MP**.
5. Привязать навык к слоту Skill HUD этого героя (1, 2, 3, Ultimate), не меняя
   HUD глобально для остальных героев.
6. Настроить развитие персонажа отдельно от уровней его навыков и сохранить
   всё в портативном JSON проекта.

Пример линейного урона: **`damage(level) = baseDamage + (level-1)*damagePerLevel`**.
Для `baseDamage=80` и `damagePerLevel=25`: ур. 1 → 80, ур. 2 → 105,
ур. 3 → 130, ур. 5 → 180. Значения ограничиваются заданным максимумом
уровня. Будущие отдельные поля: `cooldownPerLevel`, `manaCostPerLevel`,
`healPerLevel`; их эффекты будут вычисляться по формуле только в PLAY.

### Предполагаемые границы данных

- **Skill Definition** — редактируемое определение способности и формулы.
- **Prefab/Character Skill Slots** — назначение навыков и исходных уровней
  конкретному персонажу.
- **Runtime Skill State** — текущий MP, откат, накопленный опыт и
  уровень в игровой сессии (без мутации данных Builder в EDIT).
- **HUD Layout** — только координаты, внешний вид кнопок и слоты.
- **Skill Effects** — отдельные контролируемые обработчики боевой системы,
  без исполнения произвольного JavaScript из JSON и без ретаргетера.

**Эти механики пока описаны как следующее задание, а не выданы за
реализованные возможности 0.8.**

## Android

Версия 0.8.0, `versionCode=8`, идентификатор приложения
`com.phoenix.worldbuilder.engine.stable` неизменён относительно 0.6/0.7.
APK, подписанный тем же приватным ключом, должен устанавливаться как
обновление с сохранением локальных проектов. Исходная UV44 и предыдущие
тестовые ветки не затрагиваются. Полный APK собирается из кода ветки
`phoenix-engine-0.1` и 1832 GLB-файлов исходной сборки владельца.

Файлы:
- `app/src/main/assets/engine/core/phoenix-skill-layout.js`
- `app/src/main/assets/engine/builder/skill-hud-editor.js`
- `tests/test-skill-layout.cjs`
- `tests/test-skill-editor.cjs`

Автоматические тесты проверяют миграцию 0.7 → 0.8 и компоновку MOBA; на
устройстве важно проверить нажатия и отсутствие пересечения с джойстиком,
ползунком громкости и кнопкой возврата EDIT.
