# Phoenix Engine 0.6 — заметный интерфейс и постоянная идентичность APK

## Почему прежние сборки выглядели как UV44

В 0.1–0.5 новые кнопки PLAY и Prefabs находились внутри оригинальной
горизонтальной шапки UV44, которая уже содержала много строительных
инструментов. На узких экранах кнопки могли выходить за видимую область.
Название страницы и стартовый интерфейс продолжали показывать
«Phoenix Builder — Студия 2.0». Кроме того, Android package ID менялся
между каждой тестовой версией, поэтому Android устанавливал **отдельные
приложения**, а не обновления одного движка.

## Что изменено

- HTML title: **Phoenix Engine 0.6 — UV44 Builder**.
- Яркая отдельная панель **🔥 ENGINE v0.6 / ▶ PLAY / 🧬 МОБЫ / NPC**
  под шапкой Builder. Она не является дочерним элементом перегруженного
  `header.topbar` и доступна прямо в EDIT.
- Во время PLAY панель скрывается, а игровые элементы (HP, кнопка атаки,
  возрождение) остаются на экране.
- Отдельная Android-иконка приложения всё ещё основана на Builder:
  ориентируйся на **название приложения** и видимую метку ENGINE v0.6.
- Новый закреплённый APK ID:
  `com.phoenix.worldbuilder.engine.stable`.
- `versionCode = 6`, `versionName = 0.6.0`. В дальнейшем повышать
  `versionCode`, **не меняя package ID**.
- Первая тестовая сборка 0.6 подписывается отдельным **постоянным
  тестовым сертификатом**. Для будущих обновлений нужен тот же
  закрытый ключ и тот же сертификат.

## Как установить

Это **первый переход** на новый постоянный package ID, поэтому Phoenix
Engine 0.6 ставится рядом со старыми пробными приложениями UV44/Engine.
В списке Android ищи именно **Phoenix Engine 0.6**, а не старый Phoenix
Builder и не Phoenix Engine HP. При открытии появляется **ENGINE v0.6**.

Дальнейшая 0.7 может обновить **0.6 поверх** при одновременном соблюдении:
- неизменный Android package ID `com.phoenix.worldbuilder.engine.stable`;
- тот же сертификат подписи из приватного набора владельца;
- большее значение `versionCode`.

Смена или потеря ключа приведёт к ошибке подписи при попытке обновить
установленное приложение. Поэтому **ключ нельзя помещать в публичный GitHub**,
пересылать посторонним или удалять вместе с временными APK.

### Важный нюанс

Оригинальная UV44, Engine 0.3/0.4/0.5 и 0.6 имеют разные package IDs. Их
встроенные базы данных, ранее импортированные GLB и сохранённые настройки
**не переносятся автоматически между приложениями**. Экспортируй JSON и
при необходимости резервную копию GLB из старой версии, затем открой
их в 0.6. Не удаляй старую версию, пока не проверишь импорт.

## Проверка на устройстве

1. Открыть **Phoenix Engine 0.6**, найти плавающую панель
   `🔥 ENGINE v0.6` под шапкой.
2. Нажать `🧬 МОБЫ / NPC`: должен открыться редактор Prefab.
3. Нажать `▶ PLAY`: должна открыться игра с HP игрока и кнопкой атаки.
4. Вернуться в EDIT и проверить сохранение дома в JSON.
5. В библиотеке должны быть доступны все 1832 GLB-модуля оригинальной UV44
   в полной сборке из предоставленного владельцем APK.
6. Перезапустить приложение и проверить, что номер версии виден снова.

Отдельный тест `tests/test-visible-engine-ui.cjs` проверяет
неизбыточность кнопок, положение панели вне шапки, версии и постоянный ID.
**Визуальный результат на реальном Android и FPS всё ещё надо проверить.**

## Подпись

Публичный репозиторий не содержит секретных ключей.
Владелец должен хранить приватный резервный набор сертификата в безопасном
месте; использовать его для подписи следующих версий. Сертификат
`Phoenix Engine Stable Android Updates` (тестовый, не Google Play).
