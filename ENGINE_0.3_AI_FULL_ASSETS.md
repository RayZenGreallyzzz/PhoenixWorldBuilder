# Phoenix Engine 0.3 — NPC AI, GLB Animation Controller и полный Builder

## Готово в ветке

- Редактор и строительные функции восстановленной UV44, с выборочными исправлениями UV-углов.
- EDIT / PLAY и визуальный Prefab Editor.
- Контроллер GLB-анимаций `Idle / Walk / Run / Attack / Hit / Death / Cast`.
- Привязка анимационных клипов по имени без ретаргетера.
- Три режима моба: `idle` — стоит; `patrol` — ходит по маршруту вокруг точки размещения; `chase` — замечает игрока, преследует, воспроизводит Attack по дистанции и перезарядке.
- Фракция `enemy` влияет на преследование. Нейтральный NPC и союзник не атакуют игрока.
- Настройка радиуса патрулирования, дистанции обнаружения, дальности атаки, перезарядки.
- Игровые данные `phoenixGame` сохраняются вместе с редактируемым JSON-проектом. Во время PLAY перемещения мобов **не** перезаписывают исходные координаты в EDIT.
- Один WebGL-рендерер и один кадровый цикл; бюджетное обновление ИИ, не более 10 агентов за кадр. Уровень производительности на реальном Android ещё требует тестирования.

## Чего пока нет

ИИ и атаки — первая пробная версия. Есть анимационное действие Attack, но **нет нанесения урона**, здоровья игрока, полноценного боевого цикла, навмеша или обхода сложного лабиринта. Моб с препятствием может остановиться. Для Hit, Death и Cast есть настраиваемые анимационные слоты, но события, вызывающие их, ещё не реализованы.

## Возвращение всех модулей Builder из UV44

Оригинальный файл: `Phoenix_Builder_UV44_Install(3).apk`.
Подтверждённый SHA-256: `ae90230b8bf9db3d510efd2c403db768db00fbdbcf91ed538b977aec25645e85`.

В нём лежит **1832 GLB** в папке `assets/pwb/`, суммарно **74 245 524 байта** без сжатия. Их ID, имена и размеры соответствуют каталогу `js/bundled-catalog.js`, который уже присутствует в GitHub. Модели загружаются по требованию через существующую функцию UV44 `getAsset()`; не нужно заранее создавать 1832 Three.js-меша.

**Бинарные GLB-файлы намеренно не опубликованы в публичном GitHub** — надо отдельно проверить права на модели. Для собственного локального APK владельцу достаточно выполнить:

```sh
python3 tools/restore_uv44_pwb_models.py '/path/to/Phoenix_Builder_UV44_Install(3).apk'
gradle --no-daemon assembleDebug
```

Скрипт создаёт `app/src/main/assets/pwb/` и проверяет соответствие всех 1832 моделей. Эта папка добавлена в `.gitignore`, чтобы случайно не публиковать активы.

### Два разных типа Android-сборки

- **GitHub Actions APK** — проверяет код и собирается успешно, но не содержит закрытый пакет GLB.
- **Phoenix Engine 0.3 AI FULL BUILDER** — локально собранная тестовая сборка, в которую добавлены все 1832 GLB из предоставленного пользователем APK; подписана новым тестовым сертификатом APK Signature Scheme v2. Она устанавливается с отдельным идентификатором `com.phoenix.worldbuilder.engineai`.

Новый локальный тестовый сертификат **не совпадает с сертификатом других сборок**, поэтому обновления той же package ID потребуют того же ключа или удаления старой тестовой версии. Это не релиз для Google Play.

## Проверка на Android

1. Установить **Phoenix Engine AI**; оригинальную UV44 не удалять.
2. Проверить, что встроенные PWB-модули действительно отображаются в библиотеке и устанавливаются в сцену, включая стены, углы, окна и лестницы.
3. Создать небольшой дом, импортировать персонажа GLB с Idle/Walk/Attack.
4. Открыть **🧬 Prefabs**, создать моба, настроить AI: `patrol` или `chase`, выбрать клипы, HP, скорость и сохранить шаблон.
5. Поставить моба касанием пола; нажать **▶ PLAY** и проверить перемещение и Idle/Walk/Attack.
6. Нажать **⏹ EDIT**. Моб должен вернуться в исходную точку; стены и проект не должны измениться.
7. Сохранить и вновь открыть JSON, проверить количество мобов и все строительные модули.
8. Отдельно протестировать проект 700 м² и оценить FPS/плавность загрузки на реальном Android.
