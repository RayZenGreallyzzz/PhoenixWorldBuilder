# Phoenix Engine 0.2 — Prefab Editor (первый прототип)

## Что готово

**Phoenix Builder UV44** остаётся основой: строительство, камера, сенсорный
джойстик, GLB-загрузка, сохранение JSON и GLB-экспорт остаются на прежнем месте.

В ветке `phoenix-engine-0.1` теперь добавлен визуальный редактор **🧬 Prefabs**.
Он создаёт шаблоны мобов и NPC и позволяет разместить их касанием по полу или
земле без программирования.

Настраиваются:
- Имя, тип (моб / NPC), отношение (враг / нейтральный / союзник).
- GLB из существующей библиотеки Builder. Если GLB не выбран, создаётся
  яркая капсула-заглушка для тестирования.
- HP, урон и скорость.
- Привязки клипов Idle, Walk, Attack по названиям из готового GLB.

**На текущем этапе во время PLAY автоматически воспроизводится только Idle**
(если анимация есть); Walk и Attack лишь сохраняются для будущего контроллера.
ИИ, маршруты, боевые действия, коллизии с мобами и редактирование движения
пока **не реализованы**.

## Как попробовать на Android

1. Установи тестовый APK с названием **Phoenix Engine PREFAB**.
   Идентификатор `com.phoenix.worldbuilder.engineprefab` позволяет установить
   его рядом с оригинальной UV44 и предыдущими тестами.
2. Построй небольшой дом; при необходимости импортируй GLB
   кнопкой **«Импортировать GLB»** из окна **🧬 Prefabs**.
3. Вверху нажми **🧬 Prefabs**, выбери модель из библиотеки,
   задай имя, тип, HP, урон и скорость.
4. При наличии анимаций укажи точные названия Idle/Walk/Attack.
   Нажми **«💾 Сохранить шаблон»**.
5. Нажми **«👆 Поставить моба»**, затем коснись пола или земли на 3D-сцене.
   Для размещения второго экземпляра повтори действие.
6. Нажми **▶ PLAY** — перемещай персонажа привычным джойстиком,
   проверь отображение моба и его Idle.
7. Вернись кнопкой **⏹ EDIT**, открой редактор Prefabs и проверь список
   экземпляров. Удаление со сцены не удаляет строительные детали.
8. Сохрани проект через **💾 JSON**, затем загрузи его обратно:
   шаблоны и координаты мобов должны восстановиться.

## Где хранятся игровые объекты

`CleanBuilder.project()` содержит необязательный раздел
`phoenixGame` версии 1:

```json
{
  "version": 2,
  "objects": [],
  "phoenixGame": {
    "version": 1,
    "catalog": {"version": 1, "nextId": 1, "prefabs": [
      {"id":"prefab-1","name":"Волк","type":"mob",
       "faction":"enemy","assetId":"glb:example",
       "stats":{"hp":250,"damage":25,"speed":3},
       "animations":{"idle":"Idle","walk":"Walk","attack":"Attack"}}
    ]},
    "world": {"format":"phoenix-world","version":1,"nextId":1,
      "entities":[{"id":"entity-1","name":"Волк","components":{
        "prefab":{"id":"prefab-1"},
        "transform":{"position":[0,0,2],"yaw":0},
        "stats":{"hp":250,"damage":25,"speed":3},
        "character":{"type":"mob","faction":"enemy",
          "assetId":"glb:example",
          "animations":{"idle":"Idle","walk":"Walk","attack":"Attack"}}
      }}]}
  }
}
```

Старые проекты без `phoenixGame` продолжают загружаться.
Конструктор и игровые мобы находятся в отдельных группах сцены.
GLB-экспорт Builder остаётся экспортом *строительной геометрии*;
для игровых данных служит редактируемый JSON.

Имеется лимит в 80 игровых экземпляров, 300 шаблонов, чтобы первые тесты
на Android оставались контролируемыми. Анимационные миксеры работают
только в PLAY и обновляются в **существующем** кадровом цикле Builder.

## Важные ограничения

- Отсутствующие GLB в импортированном проекте будут обозначены
  заглушкой с предупреждением в редакторе. Они не потеряются из игрового JSON.
- Исходные 1832 встроенные GLB модели оригинальной UV44 **не включены в
  публичную GitHub ветку**; загружай собственные GLB.
- Для переноса GLB между устройствами используй переносимую
  резервную копию проекта, которая включает модельные данные.
- Android/WebGL производительность с большим домом и множеством мобов
  ещё не измерялась. Сначала тестировать 1–3 персонажа.
- Встроенный ретаргетер анимаций **не интегрируется**; используются только
  уже подготовленные клипы GLB.
