# Phoenix Builder FIX — сверка с Phoenix Mesh Workshop

Дата фиксации: 2026-10-31. Рабочая установленная версия Builder: `Phoenix Builder FIX`, `0.1.0-legacy-preview`, `com.phoenix.worldbuilder.legacytest`. Из исходников ветки `fix/legacy-editor-simplify-surfaces-20261022`. Референс: `RayZenGreallyzzz/QDQR` (`main`).

## Задача
Пользователь подтвердил, что облегчённый Phoenix Mesh Workshop содержит РАБОТАЮЩИЕ функции, которые в полном Builder ведут себя неправильно. Поэтому Workshop — функциональный эталон, не второстепенный проект. Не объединять APK и не переписывать Builder с нуля.

## Подтверждено просмотром исходников

## Критическое ограничение совместимости
QDQR использует ES modules, Three.js **0.186.1**, Capacitor 8 и `three-bvh-csg`; Builder — Three.js **r140**, JS-глобалы и нативную Android WebView. Нельзя просто копировать модули QDQR в Builder: нужна адаптация API, версии движка, сериализации и тестов. Сохранение текущих проектов и стабильной установки обязательно.

## Порядок проверки — блокирующие критерии
1. **Сокеты и магнит**: 2 прямые + угол 90° + дуга; нет щелей, перекрытий, скачка после Undo; неправильная геометрия подсвечена.
2. **Этажи**: первый/второй/третий этаж без X/Z дрейфа; крыша, перекрытие, стены с правильной опорой.
3. **Текстуры и изображения**: одна картинка на группу модулей и на круглую стену, без повторов и отрезания; Save/Load/Export.
4. **Проёмы**: реальная сквозная геометрия; Undo и отказ без порчи mesh при невалидной модели.
5. **Модуль и GLB**: изменение XYZ, копия, запекание, сохранение выбранного объекта, повторное открытие.
6. **Android**: проверка на Mali-G52 / 4 ГБ RAM, офлайн, реальное касание и пиковая память.

## Безопасность
- Ни одной правки в `main` или исходную `fix/legacy-editor-simplify-surfaces-20261022` без отдельной проверки.
- Все изменения в `stabilize/phoenix-builder-fix-20261031` и позже в *отдельной параллельно устанавливаемой* тестовой сборке; не повторять package id `com.phoenix.worldbuilder.legacytest` для первых тестов.
