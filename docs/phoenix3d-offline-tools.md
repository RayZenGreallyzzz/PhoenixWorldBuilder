# Phoenix 3D — офлайн-доработка пользовательского Planner 5D

## Что действительно добавлено в экспериментальную сборку

Используется оригинальный XAPK из [релиза 3D](https://github.com/RayZenGreallyzzz/PhoenixWorldBuilder/releases/tag/3D). Его 6 частей восстанавливаются побайтно, проверяются SHA-256, затем модифицируется **сам исходный APK**, а не проект PhoenixWorldBuilder.

В AndroidManifest добавляется **вторая launcher Activity** `com.phoenix3d.tools.PhoenixToolsActivity`. Оригинальная `com.planner5d.library.activity.Main` остаётся без изменений.

Экран Phoenix 3D Tools умеет:
- Выбрать **одну пользовательскую GLB-модель** Android SAF-пикером (до 48 МиБ).
- Просматривать GLB локально в WebView/Three.js, без CDN и внешних ресурсов, вращать/масштабировать, воспроизводить первую/idle-анимацию GLB.
- Импортировать PNG/JPG (до 12 МиБ, изображения до 8192×8192).
- Наносить текстуру на отдельный материал меша или размещать плоскую PNG/JPG-наклейку на поверхности касанием. Настройки сохраняются локально как JSON.
- Создавать локальную резервную копию **собственной модели, декора и настроек** с помощью SAF.
- Загружать и восстанавливать этот ZIP со своего HTTPS WebDAV/Nextcloud по кнопке, без обязательной синхронизации. Пароль не сохраняется.
- Открывать оригинальный редактор Planner через отдельную кнопку.

Код: `android-phoenix-tools/`. Сборка: `.github/workflows/phoenix3d-build-tools.yml`.

## Что НЕ реализовано

- GLB **пока не вставляется в сцену комнаты оригинального Planner**, он используется только в дополнительном редакторе **внутри того же пакета**.
- Наклейки и текстуры сохраняются в персональном инструменте и **не меняют объекты в проектах Planner**. Экспорт модифицированной модели GLB пока отсутствует.
- Резервное копирование **не включает собственные проекты Planner**, только `phoenix3d/model.glb`, `decor.bin`, `appearance.json`.
- Вход в аккаунт, запросы и системные компоненты оригинального Planner **не удалены**. Их офлайн-работа ещё не проверена на устройстве.
- Нет аппаратного Android-теста установки/запуска/выбора и просмотра GLB, есть статическая проверка AXML, DEX, пересборки, подписи и CRC.

## Особенности тестового APK

Каждый GitHub Actions запуск пока использует **новый временный ключ подписи**. Поэтому тестовая версия не обновится поверх оригинальной или ранее установленной Phoenix 3D без совпадающей подписи. **Не удаляй рабочее приложение, пока не экспортированы проекты и локальные данные.** После установки экспериментальной сборки Android может показать две launcher-иконки одного пакета: основной Planner и Phoenix 3D Tools.

Приватный ключ первоначальной пользовательской переподписи не добавляется в GitHub-репозиторий. Для обновлений поверх существующей сборки потребуется безопасно настроить **свой постоянный signing key** в GitHub Actions secrets.

## Как получить XAPK

1. Открой GitHub Actions workflow `Phoenix 3D - experimental GLB/decor tools inside Planner`.
2. Выбери **последний успешный** запуск ветки `feature/phoenix3d-planner-offline`.
3. В разделе **Artifacts** скачай `Phoenix3D-Planner-GLB-Decor-TEST`.
4. Из ZIP-артефакта извлеки `Phoenix3D_Planner_GLB_Tools_TEST.xapk`.
5. Устанавливай XAPK установщиком, который поддерживает **9 split APK**. Обычное открытие одного базового APK недостаточно.

XAPK предоставлен исключительно как **непроверенный на устройстве тест** для личного использования.


## Тестовая игровая сборка: ходьба и строительство от третьего лица (2026-11-03)

Новая дополнительная Android-активность `com.phoenix3d.tools.PhoenixGameActivity` добавлена в **тот же установленный пакет Planner**. В приложении появляется ярлык **Phoenix 3D — Игровая стройка**, также режим можно открыть из Phoenix 3D Tools. Исходный нативный Planner не заменён.

Что реализовано в отдельной игровой сцене:

- Пикер собственного GLB-персонажа (до 48 МиБ), автоматическая нормализация до ~1,8 м, проигрывание имеющихся idle/walk анимаций, запасной манекен.
- Камера от третьего лица, экранный джойстик, поворот жестом, клавиши WASD/стрелки, базовые столкновения.
- Стены, стены с реальным геометрическим дверным/оконным проёмом, полы, перекрытия и плоские крыши; длина/высота/толщина, шаг магнита 25 см, привязка стыков стен, поворот, отмена, удаление ближайшей детали.
- PNG/JPG-материал на вновь размещённых элементах. Это **не редактирует материалы нативных объектов Planner**.
- Автосохранение игрового строительства в `game-scene.json`.
- **Единый ZIP-проект**: `model.glb`, `game-scene.json`, `planner-project.json` (если импортирован отдельно), `decor.bin`, `appearance.json`. Можно сохранить или восстановить с помощью Android SAF. Резервная копия инструментов по WebDAV тоже включает игровую карту.
- Загрузка **файла JSON-проекта Planner** для приблизительного отображения стен из `Project/Floor/Room/Wall/Point` в игровом режиме без изменения оригинала. Это **не прямая интеграция в его нативный рендерер**.

Ограничения:

- **Не сделано:** запись игровых изменений в проект оригинального Planner 5D, автоматическая загрузка его локальных проектов и рендерирование GLB прямо в его нативной libGDX-сцене. Нужна отдельная проверка интерфейсов приложения и формата сохранения.
- **Не тестировалось на реальном Android:** проверены компиляция новых Activity, наличие классов и ассетов в APK, ZIP-целостность XAPK, цифровые подписи 9 APK и JavaScript smoke-тест создания стены/пола/текстуры/отмены/экспорта.
- В режиме игрового строительства пока нет сложных крыш, лестниц, полноценной физики и корректного распознавания многокомнатных планов. Режим предназначен для тестирования управления, персонажа и базовой сборки.
- Сборка использует новый временный signing key на каждом запуске CI: не устанавливай поверх оригинала; новые тестовые сборки тоже могут потребовать удаления предыдущих (предварительно экспортируй ZIP-проект).

Сборка и загрузка:
[Успешная сборка с игровым smoke-тестом](https://github.com/RayZenGreallyzzz/PhoenixWorldBuilder/actions/runs/41722168819).
В разделе **Artifacts** скачай `Phoenix3D-Planner-GLB-Decor-TEST`. Внутри ZIP находится `Phoenix3D_Planner_GLB_Tools_TEST.xapk`. Для установки всех девяти split APK используй установщик XAPK/SAI.

Проверка на планшете:

1. Запусти **Phoenix 3D — Игровая стройка**.
2. Нажми **＋ GLB персонаж** и выбери свой GLB.
3. Левым джойстиком иди, справа вращай камеру, нажми **🧱 Строить**.
4. Выбери стену, нажми **＋ Установить**, попробуй магнит, проём, пол и отмену.
5. Нажми **🎨 Загрузить PNG/JPG**, включи **Красить новый модуль** и установи модуль.
6. Нажми **Сохранить всё**, выйди и проверь **Открыть проект Phoenix ZIP**.
7. Если получишь ошибку установки/чёрный экран, приложи точное сообщение об ошибке. Автотесты не заменяют проверку на твоём Android 15, 4 ГБ RAM.
