# Phoenix 3D — full-editor preservation build (2026-11-04)

## Итог

Эта ветка **не заменяет** исходный большой редактор урезанным Three.js-прототипом. Она распаковывает шесть файлов из пользовательского релиза `3D`, восстанавливает исходный XAPK, добавляет опциональные экран GLB и игровой режим, сохраняет исходный строительный движок и переподписывает все девять APK.

Прямая ссылка для Android: [Phoenix3D_One_APK_Installer_TEST.apk](https://github.com/RayZenGreallyzzz/PhoenixWorldBuilder/releases/download/phoenix3d-full-editor-test/Phoenix3D_One_APK_Installer_TEST.apk).

Это **APK-установщик**, а не обычный один APK с объединёнными ресурсами. Android выполнит системное подтверждение установки девяти исходных компонентов после нажатия кнопки. Этот обязательный системный запрос нельзя безопасно скрыть.

## Реально выполнено

- **Исправлена причина ошибки на реальном Android.** До исправления подписанный основной APK случайно переименовывался в `phoenix_patched_unsigned.apk`, но установщик ожидал базовое имя `com.planner5d.planner5d.apk`. Теперь имя базового split APK сохраняется.
- Дополнительно вместо `AssetManager.open()` установщик использует `java.util.zip.ZipFile` и точные пути `assets/*.apk`. GitHub проверяет эти пути перед публикацией.
- Оригинальный APK распаковывается, но все **18 исходных DEX, SQLite база, 250 P3D-моделей и 13 990 остальных файлов** проверены как неизменённые.
- В Android-приложение добавлены локальные инструменты GLB, PNG/JPG и игровой режим от третьего лица с гизмо, как отдельные экраны.
- Видимое название в таблице ресурсов изменено с `Planner 5D` на `Phoenix 3D` заменами одинаковой длины, не затрагивая логику лицензирования и сетевого обмена.
- В пользовательских надписях дополнительных экранов упоминания Planner убраны.
- У **APK-установщика** теперь есть тематическая векторная иконка камина.

## Что ещё НЕ сделано

- GLB-персонаж **не вставлен в родную строительную 3D-сцену**. Он ходит и строит в отдельном игровом экране, а полный строительный редактор открывается отдельно.
- Экспорт игровых модулей непосредственно в проекты оригинального редактора не реализован.
- Оригинальные обязательные аккаунт/сетевые запросы, если они появляются в полном редакторе, не отключены. Таблица экранных строк переименована лишь частично. Гарантии полностью офлайн-запуска оригинального редактора нет.
- **Иконка установщика — стилизованный камин, не точное фото пользователя**. Точный исходный PNG не удалось включить в текущий GitHub build. Иконка внутри исходного редактора также не была полностью заменена.
- Установка/запуск на реальном Android и поведение режима с тяжёлыми GLB пока не проверены.

## Проверки

GitHub Actions: [успешная сборка](https://github.com/RayZenGreallyzzz/PhoenixWorldBuilder/actions/runs/41738128903), успешны компиляция Java и DEX, js smoke-тест, сохранение 18 DEX/базы/моделей, подписи девяти split APK, ZipFile-контроль имён компонентов, сборка APK-установщика и публикация через GitHub Releases.

## Важно перед установкой

1. Сделай резервную копию проектов рабочего приложения.
2. Скачай APK по прямой ссылке, установи и запусти его, нажми «Установить Phoenix 3D».
3. Разрешение Android на установку второго пакета является системным требованием, не запросом аккаунта.
4. Если уже стоит оригинальная или другая тестовая версия с несовпадающей подписью, Android не позволит обновление поверх неё. Не удаляй сохранения без резервной копии.
5. Установку следует считать успешной только после проверки Android на планшете.
