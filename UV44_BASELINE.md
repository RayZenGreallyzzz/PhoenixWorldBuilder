## Исправления UV и углов (выборочный обратный перенос)

Исходные поправки найдены в коммитах GitHub от 9 ноября 2026 года:
- `7b7e5d7483e5`: UV-физические размеры и дуговые/угловые стены.
- `6779abe9cbd7`: физические концы дуг и швы UV.
- `edad120a2c3a`: ориентация UV для повёрнутых и зеркальных L-углов.
- `c5d26cd442ce`: лицевые текстуры снаружи правых и левых углов.
- `b89c4bba8b1a`, `d6cdb4ee9191`: последующие исправления зеркальных GLB-стен.

Ветка UV44 из APK имеет отличающуюся структуру модулей. Поэтому вместо
слепого cherry-pick выполнен **адаптированный патч**, который:
- определяет сторону повёрнутого/зеркального встроенного угла локальной геометрией;
- классифицирует лицевую и заднюю поверхности импортированных L- и плоских GLB-стен;
- сохраняет прозрачные стеклянные поверхности при покраске.

Это **не** полный перенос всех коммитов выше и **не** утверждение, что все варианты
изогнутых стен исправлены. Отдельные случаи ещё требуют проверки на реальных проектах.

## Повторяемость

Файлы:
- `patches/uv44-corner-uv-postfix-20261109.patch`
- `tools/import_uv44_assets.py`
- `tools/apply_uv44_corner_fixes.py`
- `tests/test-uv44-postfix.cjs`

Проверка на уже восстановленной ветке:

```sh
node tests/test-uv44-postfix.cjs
```

Если потребуется **повторно восстановить** исходники из APK, сначала импорт,
а затем применение патча (импорт перезаписывает исправленные файлы):

```sh
python3 tools/import_uv44_assets.py '/path/to/Phoenix_Builder_UV44_Install(3).apk' --clean
python3 tools/apply_uv44_corner_fixes.py --check
python3 tools/apply_uv44_corner_fixes.py
node tests/test-uv44-postfix.cjs
```

Скрипт импорта пропускает GLB-библиотеку по умолчанию;
`--include-models` использовать только при разрешённой публикации.

Локально: синтаксис JS проверен, `git apply --check` проходит,
регрессионный тест исходного UV44 выявляет неверную классификацию второго
плеча L-стены (`end`), а на исправленной версии проходит
(`front/back`); также проверены повороты, отражения и стекло.

## Ограничения проверки

- Код `classes.dex` не содержит исходников Android-обёртки. Java/Gradle в
  репозитории унаследованы от более ранней версии и могут не совпадать
  с установленным APK UV44.
- Обновлённый APK **не подписан и не протестирован на Android**.
- Без WebGL/GPU нельзя подтвердить FPS, качество UV, экспорт и работу больших
  JSON-проектов на реальном устройстве.
- Ветка `phoenix-engine-0.1` пока по-прежнему основана на `main`;
  её переносить на UV44 следует после проверки Android-сборки.

Эта ветка — воспроизводимая кодовая база для дальнейшего тестирования,
а не уже подтверждённый релиз.
