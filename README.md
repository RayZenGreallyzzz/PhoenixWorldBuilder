# Phoenix Builder — стабильная база UV44

Эта ветка содержит восстановленные **76 WebView-файлов** из предоставленного APK
`Phoenix_Builder_UV44_Install(3).apk` с выборочными исправлениями
UV-развёртки и углов от 9 ноября 2026 года.

- `app/src/main/assets/` — HTML, CSS, JavaScript и декодеры из UV44.
- `surface-workshop.js` и `surface-materials.js` — патч для повёрнутых/зеркальных углов, GLB-стен и стекла.
- `patches/uv44-corner-uv-postfix-20261109.patch` — исходный патч.
- `tools/apply_uv44_corner_fixes.py` — безопасное повторное применение патча после импорта APK.
- `tests/test-uv44-postfix.cjs` — регрессионный тест углов, UV и стекла.
- `UV44_BASELINE.md` — подробные ограничения восстановления.

**Ограничения:** 1832 файла моделей из `assets/pwb/` не опубликованы в этом публичном репозитории; права на их распространение требуют отдельной проверки. Исходники Android-обёртки из APK не извлекаются автоматически: Java/Gradle часть репозитория может отличаться от APK UV44. До проверки на устройстве нельзя считать эту ветку полной идентичной установочной сборкой.

Ветка предназначена для работы над Phoenix Engine после проверки стабильности UV44. Основная `main` не изменена.
